## 🚀 Featured Projects

### 🐾 Veterinary Clinic WhatsApp Chatbot
Full-featured appointment booking chatbot for a veterinary clinic, built end-to-end in Python.
- Automated scheduling with real-time slot availability and conflict prevention
- WhatsApp integration via WAHA, with Google Calendar & Google Sheets sync (OAuth 2.0)
- SQLite backend with safe schema migrations for zero-downtime updates
- Companion Flask dashboard for staff to manage appointments
- Packaged as a standalone Windows installer for non-technical clients

`Python` `SQLite` `WAHA` `Google Calendar API` `Google Sheets API` `Flask` `Docker`

---

### 🦷 Dental Clinic Booking Bot
Appointment-scheduling chatbot adapted from the veterinary project for a dental clinic, with a live calendar dashboard.
- Interactive WhatsApp menu (procedure selection, available time slots)
- Real-time calendar dashboard synced via WebSocket/SSE as bookings come in
- SQLite as the single source of truth, decoupled from external calendar services

`Python` `SQLite` `WhatsApp API` `WebSocket`

---

### 💳 AI-Powered Financial Customer Service (ISP)
AI automation for the billing/financial department of an internet provider, integrating the company's CRM with its customer-service platform.
- Generates Pix payment codes and resends open invoices automatically, including after hours
- Detects completed payments and releases service holds automatically
- Business-rule guardrails: sensitive requests (unlocks, renegotiation) are always routed to a human agent
- Built a local testing harness to develop without depending on the live CRM API

`Python` `AI Automation` `CRM Integration` `Webhooks`

---

### 🛠️ Technical Support Chatbot ("Enia")
AI-driven technical support triage bot for internet-provider customers, handling common request flows conversationally.
- Guided flows for connection drops, slow speed, address changes, ownership transfer and plan upgrades
- Structured prompt design for accurate, detailed procedural guidance

`Python` `AI Automation` `Conversational Flows`

---

### ⚡ EV ChargeOps — FIAP Enterprise Challenge 2026 (with GoodWe)
Platform for managing shared EV charging across condominiums and campuses, built as part of FIAP's Enterprise Challenge in partnership with GoodWe.
- Owns the **AI strategy track**: clustering (K-Means/DBSCAN), anomaly detection (Isolation Forest) and demand forecasting (linear regression)
- Backend and AI modules in Python, with a React dashboard for operations

`Python` `Machine Learning` `Clustering` `Forecasting` `React`

---

### 🧠 NCAS — Núcleo Cognitivo da Aurora Siger
Academic AI-simulation prototype combining file-based data handling, logic-rule simplification (De Morgan/Boolean simplification) and prompt engineering.
- Zero-shot / few-shot prompting and structured AI output generation
- File and JSON-based data persistence for a simulated "colony" system

`Python` `Prompt Engineering` `Logic Rules`
